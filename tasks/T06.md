## Outcome and scope

Implement a source-backed original-event VM subset with decoding, expressions, variables, waits, windows, movement, traces, and stable field scheduling. Synthetic programs are verified; a real FFIX field requires actual asset decoding and host systems.

## Acceptance and evidence

| ID | Criterion | Evidence | Result |
|---|---|---|---|
| AC1 | Supported expressions preserve stack, signedness, wrapping, and assignment behavior | Expression tests | PASS |
| AC2 | Signed jumps and conditional branches use the correct instruction-relative target | Both branch polarities and signed target tests | PASS |
| AC3 | Timed waits and window waits resume exactly once on the proper clock | Wait/window tests | PASS |
| AC4 | Unsupported opcodes, traps, and loops report source offset without partial step commit | Decode, host-failure, and instruction-budget tests | PASS |
| AC5 | Multiple field entries execute in deterministic order | Report and host-effect ordering assertions | PASS |
| AC6 | Real FFIX field/event archive executes through the VM | Requires real assets and host implementation | NOT_RUN |

Decode actual event archives, implement the complete opcode/expression inventory, connect real field hosts, and compare original behavior. The current decoder accepts only the audited subset; it rejects other operations rather than ignoring them.
