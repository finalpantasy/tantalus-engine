## Remaining work

Decode actual event archives, implement the complete opcode/expression inventory, connect real field hosts, and compare original behavior. The current decoder accepts only the audited subset; it rejects other operations rather than ignoring them.


## BGI navigation foundation

`FieldNavigationMesh` now carries real vertices, floor-aware triangle references, and floor-origin offsets without exposing BGI types to the client. `FieldNavigation` projects anchors with interpolated/inverted height, selects floors deterministically, and clamps movement to the nearest valid edge. Five synthetic tests cover slopes, triangle transitions, floor selection, offset transforms, invalid indices, and empty floors.

Real `FBG_N00_TSHP_MAP001_TH_CGR_0` projection preserves anchor `(-130, 0, -648)` on triangle 0; a `[16, 0]` probe reaches `(-114, 0, -648)` on triangle 0. Evidence: `audit/bgi-field.json`. `FieldActorController` connects simulation button state to navigation and preserves readiness pauses. T12's real input scenario is recorded in `audit/field-navigation-scenario.json`; original movement feel and real event execution remain unverified.


## Real event archive

Field event ID 51 resolves to `EVT_ALEX1_TS_CARGO_3`. Its real `EVT_ALEX1_TS_CARGO_3.eb` resources are in `p0data7.bin`; seven localized candidates are reported by path ID rather than silently selecting one. `EventBinary` parses the vanilla version-2 header and all 22 entries per candidate, preserving offsets, sizes, variable counts, and flags. The selected candidate's 10,620 concatenated script bytes match UnityPy's SHA-256 exactly. Evidence: `audit/event-binary.json`.

Four entries per candidate currently decode through the existing VM. Follow-up support decodes member post-increment `0x08`, evaluates padding `0x00..0x03` as zero, writes direct post-decrement `0x05`, emits AIM `0xB8` to the host, and executes player-control `0x2C` through the current entity supplied by `FieldScene`, while preserving an explicit error when context is absent. Direct `B_OBJSPECA` reads are implemented through `LegacyEventHost::read_object_member`. Member shift assignment `0x3B` now executes the real zero-mask path with source-compatible stack cleanup; nonzero selections remain explicit errors. Expression evaluation consumes the top result without rejecting leftover stack values. Logical AND `0x27` and OR `0x28` now use explicit postfix operand ranges and skip right-side effects correctly. Member post-increment `0x08` and pre-decrement `0x0B` now execute empty selections with source-compatible two-input cleanup; missing inputs and nonzero selections remain errors. `TWIST` now emits signed digital/analog control angles, and direct pre-decrement `0x07` returns and stores its new normalized value. Custom variable `0xE3` reads its serialized ID through the host, `B_GE` comparisons and empty expressions now evaluate correctly. `BGSMOVE` `0x58` consumes three signed 16-bit expressions and continues with the pinned no-side-effect behavior; padding `103..105` and signed/unsigned 8-bit and 16-bit casts `70..73` now decode and evaluate. `B_MEMBER` `41` now supplies lazy member targets, and member XOR assignment `B_XOR_LET_E` `68` (`0x44`) builds the selected truth mask, writes the last selected target through the host, and preserves the current target for an empty mask. Member post-decrement `B_POST_MINUS_A` `9` (`0x09`) now updates every selected member, returns the last selected old value, and leaves an empty selection untouched. Member logical NOT `B_NOT_E` `15` (`0x0F`) now returns selected-member zero flags without writes; an empty mask does not require a target. Direct pre-increment `B_PRE_PLUS` `6` (`0x06`) now writes and returns the new variable or current-member value. Bitwise complement `B_COMP` `16` (`0x10`) now inverts every bit. Selected-member equality `B_EQ_E` `34` (`0x22`) now returns comparison flags without writes; empty selections do not require a target. System-variable read `B_SYSVAR` `122` (`0x7A`) now uses its serialized ID through the host and rejects unknown IDs. `NEW3` `9` (`0x09`) now decodes its source/unique IDs and emits `InitializeObject`; party aliases, default IDs, replacement, and model loading remain host responsibilities. Region initialization `NEW2` `8` (`0x08`) now emits a distinct `InitializeRegion` command with its source and unique IDs. Ordinary code initialization `NEW` `7` (`0x07`) now emits a distinct `InitializeCode` command. Navigation-triangle activity `BGIACTIVET` `154` (`0x9A`) now supports immediate and expression arguments and emits `SetTriangleActive` with the unsigned triangle ID. Field sound `FLDSND0` `197` (`0xC5`) now decodes signed code/ID operands and emits `RunSound` with three zero arguments. Attachment offset `ATTACHOFFSET` `212` (`0xD4`) now emits signed XYZ offsets for the current actor and reports missing context. Navigation attribute mask `BGIMASK` `39` (`0x27`) now emits the wrapped immediate or expression byte. List cast `B_CAST_LIST` `74` (`0x4A`) now matches the reference's empty zero-producing implementation. Right shift `B_SHIFT_RIGHT` `23` (`0x17`) now performs signed arithmetic shifts with a masked count. Angle calculation `B_ANGLE2` `102` (`0x66`) now ports the reference quadrant logic and host arctangent reads with equivalent integer output. Event opcode `pad0e` `14` (`0x0E`) now consumes its flag and yields through an explicit `Yield` instruction. `SHADOWON` `127` (`0x7F`) now emits `SetShadowEnabled` for the current actor and reports missing context. Event opcode `pad17` `23` (`0x17`) now shares the flag-consuming yield path while preserving its opcode. Message-value command `MESVALUE` `102` (`0x66`) now emits `SetTextVariable` with its script ID and signed value. Selected-member assignment `B_LET_E` `46` (`0x2E`) now computes truth masks and writes the lower target, including the empty-stack global-bit fallback. Object scaling `CHRSCALE` `159` (`0x9F`) now preserves signed-byte times-64 renderer scale and the vertical-scale byte. Vibration-rate command `VIBRATE` `250` (`0xFA`) now emits `SetVibrationFrameRate` with its signed operand. Asynchronous script request `REQ` `16` (`0x10`) now decodes level, target, and immediate function tag and emits `RequestScriptAsync`. `BGVDEFINE` `200` (`0xC8`) now emits the complete signed viewport rectangle. Entry 0 decodes completely, raising real coverage to 5 of 22 entries per candidate. Direct post-increment `B_POST_PLUS` `4` (`0x04`) now stores the new value and returns the old one. Show-objects command `POPSHOW` `214` (`0xD6`) now emits `RestoreAllVisibility`. `TIMERCONTROL` `125` (`0x7D`) now emits `SetTimerRunning` for running and paused states. Caller-targeted async request `REPLY` `22` (`0x16`) now emits `RequestCallerAsync` with its level and function tag; the earlier dialogue label was incorrect. `MJPOS` `164` (`0xA4`) now emits `CalculateExitPosition` for the host's region and actor state. Synchronous caller reply `REPLYEW` `20` (`0x14`) now emits `RequestCallerSync` once and resumes only after host-confirmed completion. `BGLATTACH` `146` (`0x92`) now emits `AttachTile` with its offsets, signed filter mode, and RGB values. Extended-opcode prefixes now accumulate `0x100` and preserve u32 opcode identities in traces/errors. Entry decoding now follows the reference's type byte, tagged function table, table-relative function offsets, and per-function boundaries instead of treating an entire entry as one instruction stream. Errors identify the entry, function index/tag, and entry-relative offset. The previous trailing-`EXT` diagnostic was therefore an artifact of missing function boundaries. Entry 1 function 1 (tag 1) now reaches unsupported expression opcode `B_SHIFT_LEFT` `22` (`0x16`) at entry offset 30 (expression offset 12). Real story behavior remains unverified.
