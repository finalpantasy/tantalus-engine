## Outcome and scope

Implement a renderer-independent authoritative simulation, explicit tick rates, ordered commands and external events, deterministic state digests, bounded presentation scheduling, and causal traces. This is synthetic engine infrastructure, not an FFIX gameplay module.

## Dependencies and ownership

Depends on T02 contracts. Local integration owner owns simulation/time files in `crates/tantalus-contracts` and `crates/tantalus-core`. No Bevy types cross the contracts boundary.

## Boundaries

The simulation uses synthetic content and does not execute FFIX scripts. The clock emits single-tick input bundles so command timing survives low presentation rates. Explicit simulation strides are used for authoritative timeline advancement. The only accepted RNG algorithm declaration is currently `none`; original algorithms are later compatibility work. State digests cover authoritative state and configuration, not rendered pixels.
