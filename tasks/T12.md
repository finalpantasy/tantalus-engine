## Outcome and scope

Build a reproducible native field → interaction → battle → rewards → save/reload loop using imported content and no original runtime fallback. The current slice proves only typed field-navigation scenarios; events, battle, and persistence remain unconnected.

## Implementation approach

Reuse the headless simulation and public navigation/game services. `ScenarioRunner` reads bounded JSON, converts steps into ordered button transitions, advances the simulation, moves the field actor through BGI, checks expected state, and returns a serializable presentation/report.
