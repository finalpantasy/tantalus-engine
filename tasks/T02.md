## Outcome and scope

Provide the public identity and inventory foundation for additive mods. Content IDs are namespaced and validated; registry changes are atomic; aliases and renames are explicit; item instances retain independent rolled state. This task does not implement FFIX item schemas or asset loading.

## Dependencies and ownership

Depends on the T01 workspace. Local integration owner owns `crates/tantalus-contracts`, `crates/tantalus-core`, and this task record. No external workers or game installation were required.

## Approach

Use validated string identities, ordered maps for deterministic serialization, explicit patch operations, and transactional registry application. Instance IDs use a deterministic nonzero sequence. Author-facing IDs remain separate from legacy numeric mappings.
