## Problem and scope

Establish a traceable reference baseline and read-only inspector, using synthetic tests and any available owned installation without implying runtime support. T01 covers reference identity, initial capability/native inventories, synthetic installation diagnostics, and the `tantalusctl install inspect` workflow. It does not import or modify game content.

## Dependencies and ownership

Local integration owner. Owned paths: Cargo workspace, `audit/`, `crates/tantalus-assets`, `crates/tantalus-tools`, and this task record. Reference checkout is ignored under `.reference/Memoria`.

## Approach

Use exact path-based resource probes, streaming SHA-256, structured reports, and no writes beneath the inspected root. Treat layout recognition and build support as different claims. Record unknown builds explicitly. Test with generated synthetic installations.
