## Remaining work

Compare the real field with an original reference, including depth, alpha/transparency, animation state, projection, and camera behavior. Real gameplay, model presentation, and skinned animation remain pending.

Capture now waits for received GPU frames with no pending Bevy render pipelines and has a bounded timeout. Fixed-frame-only warmup could save clear-color images under load; pipeline-aware readiness made both synthetic 2D and 3D pass in the same workspace run. This is host evidence, not a broad hardware compatibility claim.

## Evidence history

- `FieldMapper` maps real BGS/BGI data into renderer-independent camera/overlay/sprite/navigation contracts. Real mapping is recorded in `audit/field-mapping.json`.
- `ClientSceneAdapter::apply_field` validates resources, filters inactive sprites and cameras, spawns stable depth-ordered textured ECS sprites, and preserves native sprite dimensions separately from atlas resolution.
- AssetBundle metadata resolves the selected field's actual atlas path ID, and its decoded RGBA matches UnityPy exactly. `BundledField` supplies that same identity and image to inspection and capture without a placeholder atlas.
