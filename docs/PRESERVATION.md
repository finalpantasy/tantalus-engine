# FFIX preservation charter

## Default experience

The default profile should remain recognizably FFIX before any enhancement is enabled. Preserve original camera framing, actor scale and silhouettes, color and blending, movement response, animation holds, dialogue pacing, music transitions, and the moment control returns to the player. Do not interpolate deliberately stepped animation merely because the display supports a higher rate.

## Independent choices

- **Behavior:** original rules, selected reliability fixes, optional difficulty or alternate-rule modules.
- **Presentation:** faithful art, high-FPS output, widescreen, replacement assets, and enhanced lighting.
- **Creation:** new content, expansions, action combat, and total conversions.

These choices should compose when their technical requirements are compatible. Smooth rendering does not imply changed combat. New 3D scenes do not require abandoning ATB.

## Approved differences

Every disputed difference records the original PC result, pinned Memoria result, chosen Tantalus behavior, evidence, rationale, and whether a compatibility option is justified. Do not add switches for every internal detail, and do not preserve a defect merely because it is familiar. The machine-readable ledger is `audit/approved-differences.csv`.

## Evidence

Use reference scenarios for start/stop/turn response, narrow walkmesh passages, interaction distance, camera changes, cutscene entry, and return of control. Use static composition captures and normal-speed recordings where motion matters. Automatic checks establish technical invariants; they do not establish artistic approval.

Enhanced profiles may intentionally differ, but the difference must be declared. Universal pixel equality is not required for every enhanced renderer, and a smooth screenshot alone is not proof of faithful behavior.
