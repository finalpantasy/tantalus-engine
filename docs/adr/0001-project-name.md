# Tantalus Engine

The project is named **Tantalus Engine**, after FFIX's traveling theater troupe. The name covers both faithful performance of the original game and a stage for new creator-owned stories.

- Repository: `finalpantasy/tantalus-engine`
- Rust package prefix: `tantalus-*`
- CLI: `tantalusctl`
- Working names reserved for later components: Mognet for launcher/catalog experiences and Backstage for the workshop.

This branding decision supersedes the `ffix-rs` working name and proposed `ffixctl` command in the initial plan. It does not change the technical scope.
