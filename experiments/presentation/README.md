# Presentation experiments

This directory is reserved for bounded candidate adapters and their evidence, not a second production engine.

Use the same canonical fixtures and headless scenario for Bevy and Fyrox. Record exact versions, patches, code size, build time, correctness, resource cost, and unresolved integration work. Archive rejected experiment evidence without maintaining two production backends.

The immediate prerequisites are a known-good headless rendering result and a real reference fixture bundle. No candidate adapter is currently present.
